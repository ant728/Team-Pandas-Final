What we measure

Two signals of fragility

01

Uninsured deposit share

Depositors whose balances exceed insurance limits have more reason to withdraw when they fear losses. A bank that depends heavily on those deposits can face a faster run.

02

Securities losses relative to equity

Higher interest rates can reduce the value of existing bonds. If withdrawals force sales, those losses can eat into the bank’s financial cushion.

02 / Study design

Method

Measure each bank before the shock. Then compare its stock return with what the broader market would predict.

Before the event

December 2022 Call Reports

The pipeline takes FDIC BankFind figures and rolls bank subsidiaries up to the listed entity where needed. The dashboard reads the resulting bank-level output.

Uninsured deposit share
Estimated uninsured domestic deposits ÷ domestic deposits. When banks do not report the estimate, the pipeline approximates it from balances and counts of accounts above the insurance limit.
Securities loss / equity
The gap between amortized cost and fair value for held-to-maturity and available-for-sale securities, divided by reported equity.
HTM loss / equity
The same ratio using only held-to-maturity securities.

During the event

March 9–13, 2023

March 9 was the first trading day after SVB’s March 8 announcement. The event window covers March 9, 10, and 13.

Buy-and-hold return
Compound the bank’s daily CRSP returns over the event window, including any delisting return. For SVB and Signature, the pipeline assumes a total loss at delisting because CRSP does not report a delisting return.
Buy-and-hold abnormal return (BHAR)
Subtract the CRSP value-weighted market’s compounded return over the same window from the bank’s buy-and-hold return. This is the measure plotted.
Analysis sample
The pipeline marks an entity in sample when it matches to FDIC data, has an event return, and has positive equity. Market-model CAR is a separate measure kept in the output.
How to read the chart. Dot size shows assets. Color gets darker up to the plotted sample’s 95th percentile of securities loss relative to equity; the underlying values are unchanged. The securities ratio does not correct for all prior AFS-to-HTM transfers.
