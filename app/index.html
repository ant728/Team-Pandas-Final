Scientific recipe

Measure before the event.
Keep the accounting visible.

Data → measures → returns → dashboard

  1. Download Q4 2022 bank financials from FDIC BankFind; aggregate subsidiaries using ownership in that quarter.
  2. Uninsured share = uninsured domestic deposits / domestic deposits.
  3. Baseline securities exposure = (HTM cost − fair value + AFS cost − fair value) / equity. This omits earlier transferred losses.
  4. Headline BHAR = compounded stock return minus compounded CRSP value-weighted market return, March 8 close to March 13 close. Retain summed CARs as alternatives.
  5. Keep unmatched returns and report coverage. CRSP is loaded; unknown SVB and Signature delisting returns remain missing.

Zions: a transfer-aware measure

Recommended definition: (HTM gap + AFS gap + remaining pretax transferred securities loss) / equity. The approximate Zions diagnostic uses the disclosed transfer amount; it is not a fully reconciled year-end balance or a comparable full-sample ranking.

Total AOCI is not a substitute: it includes taxes and non-securities components. See the sourced methodology note.

Historical API data may contain later amendments. Cross-bank FFIEC comparisons and a full transfer-loss collection are outstanding. Bank subsidiary aggregates can differ from consolidated holding-company accounts.
